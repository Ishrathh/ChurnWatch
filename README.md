# ChurnWatch

ChurnWatch is a Deep Learning ensemble model for predicting customer churn with a focus on customer centric features. This project is built with a Flask backend and a Next.js frontend.

In fulfilment of the requirements for the course "Bsc. Computer Science" at the [University of Westminster](https://www.westminster.ac.uk/), this project is built with a focus on production readiness and scalability.

## Project Structure

The project is structured as follows:

- `app`: The Next.js frontend.
- `server`: The Flask backend.

## Setup & Running

You will find specific instructions to setup & run the frontend interface in the `app` directory and the backend server in the `server` directory.
